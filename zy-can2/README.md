# STM32F103电机控制系统学习记录

## 项目概述

本项目是一个基于STM32F103系列单片机的电机控制系统，主要用于学习和实践CAN通信、PID控制算法以及嵌入式系统开发。项目实现了一个双环PID控制器（角度环和速度环）来精确控制电机的位置和速度，通过CAN总线与电机驱动进行通信，并支持通过串口进行参数调优和数据监控。

## 硬件要求

- STM32F103系列开发板
- 支持CAN通信的电机驱动（如C610、C620等）
- 电机（推荐使用无刷电机）
- USB转串口模块（用于调试）
- 必要的连接线和电源

## 软件架构

### 1. 整体架构

项目采用模块化设计，主要包含以下模块：
- 主程序模块（main.c）：系统初始化、主循环控制
- CAN通信模块（can.c）：电机通信协议实现
- PID控制模块（pid.c）：双环PID算法实现
- 定时器模块（tim.c）：系统定时中断
- 串口通信模块（usart.c）：调试信息输出和参数配置

### 2. 控制流程

1. **初始化阶段**：配置时钟、外设（GPIO、CAN、UART、TIM）、PID参数
2. **控制循环**：
   - 每2ms执行一次PID计算和电流发送
   - 每20ms通过串口发送一次监控数据
3. **中断处理**：
   - CAN接收中断：处理电机反馈数据
   - 串口接收中断：处理上位机命令

## 主要功能模块

### 1. PID控制模块

实现了双环PID控制策略：
- **角度环（外环）**：控制电机角度位置，范围-720°到720°
- **速度环（内环）**：控制电机转速，作为角度环的执行层

主要函数：
- `PID_Init()`：初始化PID参数
- `PID_Calculate()`：PID算法计算
- `Angle_Normalization()`：角度归一化处理

PID参数配置：
```c
// 角度环PID初始化（外环）
angle_pid.Kp = 0.8f;     // 比例系数
angle_pid.Ki = 0.01f;    // 积分系数
angle_pid.Kd = 0.05f;    // 微分系数
angle_pid.output_max = 200.0f;      // 输出限幅
angle_pid.integral_max = 300.0f;    // 积分限幅

// 速度环PID初始化（内环）
speed_pid.Kp = 20.0f;    // 比例系数
speed_pid.Ki = 0.3f;     // 积分系数
speed_pid.Kd = 0.08f;    // 微分系数
speed_pid.output_max = 16000.0f;    // 输出限幅
speed_pid.integral_max = 16000.0f;  // 积分限幅
```

### 2. CAN通信模块

实现与电机驱动的通信：
- **发送**：发送电流指令到电机
- **接收**：接收电机反馈数据（角度、速度、电流、温度）

主要函数：
- `MX_CAN_Init()`：CAN初始化配置
- `CAN_Send_Current()`：发送电流命令
- `Motor_Feedback_Update()`：更新电机反馈数据

CAN配置参数：
- 波特率：500Kbps（系统时钟72MHz，分频4，BS1=6TQ，BS2=2TQ）
- 模式：正常模式
- 过滤器：接收所有标准ID的消息

### 3. 串口调试模块

提供调试和参数调整功能：
- 通过串口接收命令调整PID参数和目标角度
- 周期性发送电机状态数据用于监控

命令格式：
- `p<value>`：设置角度环Kp参数
- `i<value>`：设置角度环Ki参数
- `d<value>`：设置角度环Kd参数
- `P<value>`：设置速度环Kp参数
- `I<value>`：设置速度环Ki参数
- `D<value>`：设置速度环Kd参数
- `T<value>`：设置目标角度（-720到720度）
- `R`：重置PID积分值

### 4. 主程序流程

```
初始化系统时钟
初始化外设（GPIO、CAN、UART、TIM）
初始化PID参数
配置CAN过滤器
启动CAN、定时器和串口中断
设置初始目标角度

主循环：
  每2ms：
    1. 计算角度环PID输出作为速度环目标
    2. 计算速度环PID输出作为电流值
    3. 通过CAN发送电流命令
  
  每20ms：
    1. 发送监控数据到串口
```

## 使用说明

### 1. 硬件连接

- 将STM32的PA11（CAN_RX）和PA12（CAN_TX）连接到CAN收发器
- 将CAN收发器连接到电机驱动的CAN接口
- 将USB转串口模块连接到STM32的USART1（PA9/PA10）
- 确保所有设备共地并连接正确的电源

### 2. 参数调试

使用串口助手（如VOFA+）连接到开发板，波特率默认为115200bps。

#### 调整PID参数：
- 发送 `p1.0` 设置角度环Kp为1.0
- 发送 `P30.0` 设置速度环Kp为30.0

#### 设置目标角度：
- 发送 `T90.0` 设置目标角度为90度

#### 监控数据格式：
```
目标角度,实际角度,目标速度,实际速度,输出电流,角度环Kp,速度环Kp
```

## 学习要点

### 1. 双环PID控制

双环PID是一种级联控制结构，外环控制位置，内环控制速度。这种结构可以提高系统的稳定性和响应速度：
- 外环（角度环）：精度要求高，但响应速度可以相对较慢
- 内环（速度环）：响应速度要求快，直接控制执行机构

### 2. CAN总线通信

CAN总线是工业控制中常用的通信协议，具有以下特点：
- 高可靠性，支持错误检测和自动重发
- 优先级机制，保证重要消息优先传输
- 多节点支持，适合分布式控制系统

### 3. 嵌入式系统实时控制

- 使用定时器中断确保控制周期的精确性
- 通过中断处理异步事件（CAN接收、串口接收）
- 合理设计任务优先级，保证关键任务的实时性

## 优化建议

1. **参数自整定**：可以实现自动PID参数整定算法，如Ziegler-Nichols方法
2. **多电机控制**：扩展支持多电机协同控制
3. **保护机制**：添加过流、过热保护功能
4. **数据记录**：增加数据记录功能，便于分析系统性能
5. **上位机界面**：开发可视化上位机，提供更友好的调试界面

## 注意事项

1. 初次使用前，请确保正确连接硬件，避免短路和接反电源
2. 调试时，建议先使用较小的PID参数，逐步调整以避免电机剧烈抖动
3. CAN总线需要正确端接120Ω电阻以保证通信质量
4. 定期检查电机温度，避免长时间过载运行
