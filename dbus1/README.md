# DBUS遥控器接收解析学习记录

## 硬件配置

- **主控芯片**：STM32F4系列微控制器
- **串口配置**：
  - USART1，波特率100000bps
  - 数据位：8位
  - 停止位：1位
  - 校验位：偶校验
  - 无硬件流控制
- **GPIO引脚**：
  - PB6：USART1_TX
  - PB7：USART1_RX
- **DMA配置**：
  - 通道：DMA2_Stream2，通道4
  - 模式：循环模式，外设到内存
  - 优先级：高

## 软件架构

### 主要文件

- **main.c**：包含主程序逻辑、数据结构定义和串口接收回调函数
- **usart.c/h**：串口配置和初始化
- **dma.c/h**：DMA配置
- **gpio.c/h**：GPIO配置

### 数据结构

```c
typedef struct
{
   uint16_t ch0;     // 通道0数据
   uint16_t ch1;     // 通道1数据
   uint16_t ch2;     // 通道2数据
   uint16_t ch3;     // 通道3数据
   uint16_t ch4;     // 通道4数据
   uint8_t s1;       // 拨码开关S1状态
   uint8_t last_s1;  // 上一次S1状态
   uint8_t last_ch4; // 上一次ch4状态
   uint8_t s2;       // 拨码开关S2状态
}RC_Ctl_t;
```

## DBUS协议详解

### 数据格式（18字节数据包）

| 域 | 通道0 | 通道1 | 通道2 | 通道3 |

| 偏移(bit) | 0-10 | 11-21 | 22-33 | 34-44 |
| 长度(bit) | 11 | 11 | 11 | 11 |
| 符号位 | 无 | 无 | 无 | 无 |
| 范围 | 最小值364，中间值1024，最大值1684 | 最小值364，中间值1024，最大值1684 | 最小值364，中间值1024，最大值1684 | 最小值364，中间值1024，最大值1684 |
| 功能 | 无符号类型 遥控通道0 | 无符号类型 遥控通道1 | 无符号类型 遥控通道2 | 无符号类型 遥控通道3 |

#### 第6字节：拨码开关状态（S1-S2）

| 域 | S1 | S2 |
|----|----|----|
| 偏移(bit) | 44-46 | 46-48 |
| 长度(bit) | 2 | 2 |
| 符号位 | 无 | 无 |
| 范围 | 最小值0，最大值3 | 最小值0，最大值3 |
| 功能 | 遥控拨码开关S1开关值 | 遥控拨码开关S2开关值 |

#### 第9-10字节：鼠标X轴

| 域 | 鼠标X轴 |
|----|---------|
| 偏移(bit) | 48-63 |
| 长度(bit) | 16 |
| 符号位 | 有 |

| 功能 | 鼠标在X轴上的移动值 |

#### 第11-12字节：鼠标Y轴

| 域 | 鼠标Y轴 |

| 偏移(bit) | 64-79 |

| 符号位 | 有 |
| 范围 | 最小值-32768，静止值0，最大值32767 |
| 功能 | 鼠标在Y轴上的移动值 |

#### 第13-14字节：鼠标Z轴

| 域 | 鼠标Z轴 |

| 偏移(bit) | 80-95 |

#### 第15字节：鼠标左键

| 域 | 鼠标左键 |

### 数据解析算法

在`HAL_UART_RxCpltCallback`函数中实现了数据解析：

```c
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if(huart->Instance==USART1)
    {
        RC_Ctl.ch0=((buffer[0]|buffer[1]<<8))&0x07ff;
        RC_Ctl.ch1=((buffer[1]>>3|buffer[2]<<5))&0x07ff; 
        RC_Ctl.ch2=((buffer[2]>>6|buffer[3]<<2|buffer[4]<<10))&0x07ff;
        RC_Ctl.ch3=((buffer[4]>>1|buffer[5]<<7)) &0x07ff;  
        RC_Ctl.s1=((buffer[5]>>4)&0x000C)>>2; 
        RC_Ctl.s2=(buffer[5]>>4|0x0003);
        RC_Ctl.ch4=buffer[16]|(buffer[17]<<8);
    }
}
```

## 使用说明

1. 确保硬件连接正确：将DBUS遥控器接收机与STM32的PB6(PB_TX)和PB7(PB_RX)连接
2. 编译并烧录程序到STM32开发板
3. 程序会自动初始化串口和DMA，并开始接收遥控器数据
4. 接收到的数据会通过回调函数自动解析到`RC_Ctl`结构体中
5. 可以在主循环中使用`RC_Ctl`结构体中的数据来控制设备

## 注意事项

- 确保遥控器和接收机已正确配对
- 串口波特率必须设置为100000bps，且使用偶校验(遇到的问题)
- 数据解析时需要注意位操作的正确性，特别是对于跨字节的数据(遇到的问题)
- 如需使用其他通道或功能，可能需要修改数据结构和解析函数
